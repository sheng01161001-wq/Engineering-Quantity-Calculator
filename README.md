# 小棒槌－工程數量計算（v26）

手機用的工程數量計算 App。輸入尺寸，就會自動算出面積、泥作工項材料用量、鋼筋、混凝土和清運數量，結果可以匯出成 PDF 或 Excel 報表。

- 線上網址：https://sheng01161001-wq.github.io/Engineering-Quantity-Calculator/
- 原始碼：https://github.com/sheng01161001-wq/Engineering-Quantity-Calculator

---

## 1. 這個程式是做什麼的

這是給工地現場用的計算工具，手機上可以「安裝」成 App（PWA，可安裝的網頁 App），沒有網路也能用。

### 面積頁（長 × 寬，或直接輸入 m²）
- **面積與坪數**：可以輸入「相同數量（處）」，數量會一起乘進去。
- **工項用量**：資料來自單價分析表（東光段 單價分析表1140707），只算用量，不含價格、品牌和型號。共 147 個工項、8 個分類。地磚和外牆要先選「工法」，再選尺寸：
  - 地磚（54 項）：工法有硬底／軟底／騷底，每種 13 個尺寸（10×10～120×120，含 15×60、15×75），硬底另有 6×22.7（含勾縫劑，跟填縫劑二選一）；木地板 5 種工法（超耐磨 8/10/12mm、SPC 4/5/6mm、海島型表層 0.6/2/3mm、實木 15/18mm、PVC塑膠 2/3mm黏貼與 5mm卡扣），地板以片、防潮布與靜音墊以捲計，矽利康依伸縮縫寬×深計算，收邊條依每 m² 牆邊 1m（以實際周長為主），是網路案例與業界參考值
  - 壁磚（13 項）：10×10、20×20、25×40、30×30、15×60、15×75、30×60、40×80、45×90、60×60、80×80、60×120、75×150（打底另計）
  - 外牆（25 項）：工法有貼磚（一丁掛、小口磚、二丁掛、四丁掛、15×45、30×60、60×60，含 1:3 砂漿打底與勾縫劑）；石材（乾掛 3/4cm、背栓乾掛 2.5/3cm、濕式灌漿 2/3cm、黏貼 1.5/2cm，以才計）；塗料（水泥漆、彈性水泥漆、仿石漆、防水塗料、氟碳漆，各分含粉光打底／不含打底）。石材五金與塗料用量是網路案例參考值
  - 內牆（3 項）：1:3 水泥粉刷、1:3 水泥打底、1:2 水泥粉刷（防水粉刷）
  - 地坪打底（2 項）、樓梯（2 項）、隔間／砌磚（20 項：砌紅磚 1/4B、1/2B、1B、1.5B；白磚 7.5～20cm；輕隔間乾式雙面單層／雙層 C65～C100、濕式灌漿 C75～C100）、油漆（28 項：水泥漆、乳膠漆、晴雨漆、防霉漆、黑色塗料、只批土，各分牆面／平頂／輕隔間／地下室分色帶／不批土）
  - 材料分析的 Excel 在 `cleanup-estimate-system\材料分析\材料分析_20261106.xlsx`
- **扣除開口**：可以輸入門窗面積，計算時會扣掉。
- **叫料數量**：包、塊、支、桶這類單位，會另外顯示無條件進位後的叫料數。
- **乾掛石材**：自動把 m² 換算成才（1 m² ≈ 10.89 才）。
- **工項清單**：可以把好幾個工項加入清單，同一種材料會合併加總，例如一間浴室＝內牆打底＋壁磚＋地磚。
- **鋼筋用量（網狀配筋）**：可以選 #3～#10、間距、單層或雙層、搭接率，算出根數、長度、重量和 12m 鋼筋支數。

### 體積頁（長 × 寬 × 高）
- **混凝土**：含損耗，叫料進位到 0.5 方，並算出預拌車數。
- **鋼筋**：依構件的含筋率估算重量（樓板、梁、柱、牆、基礎，也可以自訂）。
- **廢棄物／土方清運**：算出實方、鬆方、重量和車次。車次會同時看容量和載重，取比較多的那個，避免超載。

### 匯出與其他
- **匯出 PDF**：A4 版面，資料多會自動分頁，每頁有頁碼。
- **匯出 Excel**：產生 .xlsx 檔，數字是數值格式，可以直接加總。
- 可以填「工程名稱」，會印在報表上，也會放進檔名。
- 產生的檔案可以直接分享到 LINE、存到手機，或下載。
- 可以複製文字結果、存入計算紀錄（最多 30 筆）。
- 所有計算都在手機上完成，資料不會上傳到任何地方。

| `index.html` | **主程式**。畫面、樣式和所有計算邏輯都在這個檔案裡，包括：工項用量資料（程式裡的 `WI` 資料表）、面積／鋼筋／混凝土／清運的計算、工項清單、PDF 產生器（畫在畫布上再包成 PDF）、Excel 產生器（自己組 .xlsx）、計算紀錄、安裝按鈕。不需要任何外部套件。 |

## 3. 安裝與執行

### 給使用者：在手機上安裝
1. 第一次打開請在**有網路**的地方：https://sheng01161001-wq.github.io/Engineering-Quantity-Calculator/
2. **Android（Chrome）**：按頁面最下面的「📲 安裝到手機」，或按瀏覽器選單裡的「安裝應用程式」。
3. **iPhone**：一定要用 **Safari** 打開。在 LINE 裡點連結的話，要先選「用 Safari 開啟」。接著按分享按鈕 →「加入主畫面」，新版 iOS 要打開「以網頁 App 打開」，再按「新增」。
4. 之後都從桌面上的圖示打開。頁面最下面會顯示版本號（目前是 v26）。

### 在電腦上執行或測試
- **最簡單**：直接點兩下 `index.html`，用瀏覽器打開就能用。這個方式不會有離線和安裝功能，因為瀏覽器只允許 http/https 網址使用這兩個功能。
- **完整測試**（含離線、安裝）：在這個資料夾開一個簡單的網頁伺服器，例如
  ```
  python -m http.server 8000
  ```
  然後打開 http://localhost:8000/

### 部署或更新到 GitHub Pages（免費）
1. 把這個資料夾裡的檔案全部上傳到 GitHub 的公開儲存庫：Add file → Upload files → Commit changes。
2. 第一次要開啟網站功能：Settings → Pages → Source 選「Deploy from a branch」→ Branch 選「main」、資料夾選「/ (root)」→ Save。
3. 等 1～3 分鐘網站就會更新。使用者有網路時打開 App，就會自動換成新版。

### 修改時要注意
- 改了 `index.html` 之後，要同時把 `sw.js` 裡的 `CACHE` 版本號加一（例如 `qcalc-v25` → `qcalc-v7`），也要改 `index.html` 最下面的「版本 vX」。不改的話，有些手機會一直用舊版。
- 要改工項用量，去改 `index.html` 裡的 `const WI = [...]`。每個工項的格式是：
  `{"c":"分類","m":"工法(可省略)","s":"選單顯示的尺寸(可省略)","t":"工項名稱","L":[["材料","單位",每單位用量,"備註"], ...]}`
  乾掛石材這類以「才」計的工項，要多加 `"su":"才"`。
- 手機桌面上的圖示和名稱不會自動更新。要換圖示的話，使用者要把 App 刪掉再重新安裝。

## 4. 目前進度與尚未完成

### ✅ 已完成
- 面積頁：用尺寸或直接輸入 m² 計算、算坪數、36 個工項的用量、扣除開口、叫料進位、合併清單
- 鋼筋網狀配筋計算
- 體積頁：混凝土、含筋率估鋼筋、廢棄物／土方清運車次
- 匯出 PDF、Excel，分享到 LINE 或手機
- 複製結果、計算紀錄
- 可安裝的 App、離線使用、自訂圖示
- 部署在 GitHub Pages，可以跟同事一起使用

### ⚠️ 需要留意的地方
- **油漆用量**是估算值：原本的單價分析表只有施作面積，所以油漆量是用「每加侖單遍約 30 m²、刷 2 遍」估出來的，App 上有標「(估)」。
- **輕隔間**工項只有面積和灌漿材，沒有骨架和板材的明細，因為原表是用整項分包計價。
- **壁磚工項**沒有包含打底，要另外加「內牆 1:3 水泥打底」或「內牆 1:3 水泥粉刷」。
- **體積頁的含筋率**、清運的鬆方係數和車型數值都是一般經驗值，實際請依結構圖和合作廠商的數字調整。
- **資料只存在每個人自己的手機**：工項清單、計算紀錄、工程名稱都一樣。刪掉 App 或清除瀏覽器資料就會不見，也不能跟其他人同步。
- **PDF** 是用圖片方式產生，所以檔案裡的文字不能選取或搜尋。
- **工項用量資料**是用 LE~COIN 大樓新建工程（東光段）的單價分析表整理的（2025/07 版本）。其他工程如果用量不同，要換成新的資料。
